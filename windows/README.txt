aesa-monitor (Windows 실행파일)
================================

AESA 데이터 처리부의 통신(처리부 <-> 모의기, 처리부 <-> 운용통제기)을 캡처해서 빔·추적·통신 상태를
보여주는 모니터·분석기입니다. 처리부에는 아무것도 보내지 않습니다.

들어 있는 파일
--------------
  aesa-monitor.exe     모니터. 두 번 눌러 실행합니다. 처음 실행하면 옆에 monitor.env(모니터 설정)를 만듭니다.
  .env                 처리부 설정(aesa-processor의 .env.example). 처리부·운용통제기·모의기 주소와 추적 설정을
                       여기서 읽습니다. 처리부 .env를 바꿨다면 그 파일로 덮어쓰세요.
  setup_network.bat    노트북 IP 고정 설정(관리자 권한). 아래 '노트북 IP' 참고.
  setup_network.ps1    setup_network.bat이 실행하는 스크립트.
  setup_power.bat      시연 중 노트북이 잠들지 않게(관리자 권한). 아래 '노트북 전원' 참고.
  prepare_board_sd.bat 처리부 SD 준비: board 폴더의 스크립트와 노트북 ssh 공개키를 SD에 넣음.
  board\               처리부 보드용 스크립트(run_aesa.sh, install_board.sh, board.conf, README.txt).

모두 같은 폴더에, 쓰기 가능한 곳(바탕화면·문서 등, Program Files 아래는 피함)에 두세요.

필요한 것
---------
  - Windows 10 / 11 (64비트). Python은 필요 없습니다.
  - 실시간 캡처: Wireshark(설치할 때 Npcap도 함께). https://www.wireshark.org/download.html
    Npcap 설치 화면의 "Restrict Npcap driver's access to Administrators only"는 끈 채로 두세요.
  - 녹화(.aesarec)·처리부 로그·pcap 파일을 열어 보기만 할 때는 Wireshark가 없어도 됩니다.

노트북 IP (setup_network.bat)
-----------------------------
  처리부(Zynq)는 192.168.10.20:3200입니다. 노트북 유선 랜카드에 같은 네트워크 주소를 고정으로 넣습니다.
  setup_network.bat을 두 번 누르고(관리자 확인 창 '예'), 랜카드 번호와 구성을 고릅니다.
    1. 모니터 노트북만                          192.168.10.30
    2. 노트북 1대(모니터·운용통제기·모의기 모두)   192.168.10.30, 192.168.10.10, 192.168.10.100
    3. 자동(DHCP)으로 되돌리기
  설정은 재부팅해도 유지됩니다. USB 랜 어댑터를 다른 것으로 바꾸면 다시 실행하세요.

캡처할 랜카드
-------------
  monitor.env의 MONITOR_CAPTURE_COMMAND에 있는 {interface}는 처리부와 같은 네트워크(192.168.10.x)
  주소를 가진 랜카드로 자동으로 바뀝니다. 랜카드 이름이나 장치 ID를 적을 필요가 없습니다.
  처리부를 127.0.0.1로 지정하면(가짜 처리부 시험) 루프백을 캡처합니다.
  자동으로 못 찾으면 상단 바 처리부 점(●)에 마우스를 올렸을 때 이유가 나옵니다.

  주의: 일반 스위치에서는 다른 장비끼리의 패킷이 이 PC로 오지 않습니다. 이 PC가 운용통제기·모의기를
  직접 실행하거나(노트북 1대), 처리부 앞에 브리지로 끼어 있어야 전체 통신이 보입니다.
  모니터는 운용통제기·모의기 접속보다 먼저 켜세요(한 번만 오는 운용 명령·자세 정보를 놓치지 않게).

노트북 전원 (setup_power.bat)
-----------------------------
  1. 시연용으로 바꾸기: 절전·최대 절전·덮개 닫을 때 동작·USB 선택적 절전·유선 랜카드 절전을 끕니다.
     바꾸기 전 값은 %LOCALAPPDATA%\aesa-monitor\power-backup.json에 저장합니다.
  2. 원래대로 되돌리기(랜카드 절전은 장치 관리자에서 직접 켭니다).

처리부 보드 준비 (한 번)
-----------------------
  1. 처리부 SD를 노트북에 꽂고 prepare_board_sd.bat 실행
     -> SD의 aesa 폴더에 보드 스크립트 복사, 노트북 키(%USERPROFILE%\.ssh\aesa_board_ed25519)를 만들고
        공개키를 aesa\authorized_keys에 넣습니다. 필요하면 SD의 aesa\board.conf에서 자동 실행을 켭니다.
  2. SD를 보드에 꽂고 시리얼 콘솔에서 petalinux로 로그인한 뒤
       sudo sh /run/media/mmcblk0p1/aesa/install_board.sh
     (처음 로그인이면 비밀번호를 새로 정하라고 나옵니다. 자세한 내용은 board\README.txt)
  3. 모니터 [메뉴] -> [처리부 제어] -> [상태]가 성공하면 끝.

처리부 제어 (모니터 [메뉴] -> [처리부 제어])
------------------------------------------
  상태 / 시작 / 재시작 / 중지 / 시각 맞추기 / 로그 가져오기 / 보드 끄기
  [시작]은 노트북 시각을 보드에 넣은 뒤 처리부를 켭니다(보드에 시계가 없어 로그 이름 날짜가 맞게).
  접속 정보(petalinux@192.168.10.20)는 [로그 가져오기] 창의 값을 같이 씁니다.

시연 순서
---------
  보드 전원 -> 노트북: aesa-monitor.exe -> [처리부 제어] -> [시작]
  -> 운용통제기 운용 ON -> 모의기 시나리오 로드
  끝: [중지] -> [로그 가져오기] -> [보드 끄기] -> 10초 뒤 보드 전원 끄기

문제가 있을 때
--------------
  exe 옆의 aesa-monitor.log에 실행 기록과 오류가 남습니다.
